Installation

Inside the download zip are folders for Linux, macOS and Windows. Open the folder for your system and copy the Mutant Squelch.vst3 bundle inside it to your VST3 directory.

  • Linux: Linux/Mutant Squelch.vst3 → ~/.vst3/Mutant Squelch.vst3
  • macOS: macOS/Mutant Squelch.vst3 → ~/Library/Audio/Plug-Ins/VST3/Mutant Squelch.vst3
  • Windows: Windows\Mutant Squelch.vst3 → C:\Program Files\Common Files\VST3\Mutant Squelch.vst3

The macOS build is signed but not notarised, and the Windows build is unsigned. If macOS refuses to load the plugin, clear its quarantine flag:

Installed for the current user (~/Library/Audio/Plug-Ins/VST3/):

xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Mutant\ Squelch.vst3

Installed for all users (/Library/Audio/Plug-Ins/VST3/):

xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/Mutant\ Squelch.vst3

Mutant Squelch is DRM-free and requires no authorisation. If you use and enjoy this plugin, please buy a copy to support its development.

The zip also carries a library of example tuning files in Tunings/scl/ and Tunings/kbm/. Keep them wherever you like and drag them onto the plugin to load them.

Demo

The demo version is fully-featured so you can test all the plugin features to determine if it's right for you. It outputs 10 seconds of silence after every minute of playing as a limitation.

Any sessions or presets you save using the demo version will remain compatible with the paid version. If you do buy the paid version, simply remove the demo VST3 and replace it with the version downloaded from the Polar customer portal, then rescan plugins to continue where you left off.

Update Version

Mutant Squelch has no auto-updater and never connects online to check for updates. You can check the Polar customer portal for new versions and replace the plugin files by hand.

  1. Quit your DAW so the old bundle isn't loaded.
  2. Download the current zip from the Polar customer portal. The file name carries the version, as in Mutant-Squelch-X.Y.Z.zip.
  3. Open the folder for your platform and copy Mutant Squelch.vst3 over the installed copy, replacing the whole bundle. Don't merge the two folders: replace the old one outright.
  4. Reopen the DAW and rescan plugins if it asks.

Updating only touches the plugin bundle. Your presets, settings.xml, tuning files and saved sessions live outside it, so they survive the swap unchanged.

Uninstallation

  1. Quit your DAW.
  2. Delete the plugin bundle:
    • Linux: ~/.vst3/Mutant Squelch.vst3
    • macOS: ~/Library/Audio/Plug-Ins/VST3/Mutant Squelch.vst3
    • Windows: C:\Program Files\Common Files\VST3\Mutant Squelch.vst3
  3. Optionally delete settings.xml and its neighbouring Presets folder, in the location listed under Settings and Library. These are your preferences and saved presets, so keep them if you plan to reinstall.

Topology

Mutant Squelch uses a classic subtractive topology. Oscillators generate sound, which is then shaped by amplitude and filters.

Oscillator → Filter Module → Amplifier → Warm Filter → Output Gain → DC-blocking Safety Filter (1-pole HPF at 3 Hz) → Output

Additive Engine

The additive synthesis engine generates complex sounds by summing sine partials, up to 512 per voice. The engine is band-limited, culling partials below 20 Hz to avoid inaudible infrasonic energy and above Nyquist to avoid aliasing.

Additive synthesis can be heavy on the CPU! If you hit performance issues, try reducing the Quality setting.

Additive FX

All oscillators that utilise the additive engine also support the additive FX section. These FX directly transform the spectral content before it's rendered:

Overtone Stretch

The 1st overtone's frequency is multiplied by the stretch, the 2nd overtone's frequency by the stretch twice over, and so on.

Overtone Conform-to-Scale

Quantises partials to the nearest scale steps of the currently loaded tuning!!! This is a headline feature that was actually the subject of my final year project at university, and 13 years later here I am reimplementing it as a synth plugin.

Amount

Quantise overtones to the nearest note of the currently loaded scale.

Ceiling

The overtone number from which conforming is skipped. Conformed timbres have sparse upper overtones, so skipping the conform after a certain number of overtones can keep the timbre sounding dense.

Overtone Offset

Shifts partials in Hz, scaled by their index. The 1st overtone is shifted this many Hz, the 2nd overtone twice this many Hz, and so on.

Envelopes

Mutant Squelch has envelopes for amplitude, filter cutoff frequency, voice pitch, overtone stretch, overtone conform, and the Modulator oscillat's mod-index. Each envelope has the same contour as below:

  • Attack: Linear, 0-10s
  • Decay: Exponential, 0-10s
  • Sustain: 0-100%
  • Release: Exponential, 0-10s

Mono Legato mode does not retrigger any envelopes when one voice steals another. For retriggering, use Mono mode instead.

Resynthesis Oscillator

Resynthesis loads in an audio file, analyses it into a sequence of spectral frames, then plays back the frames using additive synthesis. This is an extremely lossy process and some audio sources will sound mangled when played back through the Resynthesis oscillator. It is a spectral oscillator, not a sampler: the audio itself is never stored.

Loading Audio

Click Load Audio... and choose a file, or drag one audio file from the desktop onto the plugin window. Once a source is loaded the button reads Replace....

WAV, AIFF, FLAC, Ogg Vorbis and MP3 are supported. Channels are mixed down to mono, so an out-of-phase stereo pair can cancel and be reported as silent. The status line shows analysis progress, the frame count, the stored size, a truncation warning and any read error.

FLAC files. The bundled FLAC reader can zero-fill the last partial block of a file whose length is not a multiple of the encoder's block size. Up to about a tenth of a second at the end may analyse as silence, and a FLAC shorter than one block reads as silent. Use WAV or AIFF to avoid the issue.

Analysis Limits

Only the first 20 seconds of a file get analysed. Each frame holds at most 512 partials, though a small FFT size of 1024 will result in max 256 partials. Files above 48 kHz are converted to 48 kHz for analysis without changing their duration or playback pitch.

FFT

Sets the analysis window and frame rate. Changing it re-analyses the file.

  • 1024 keeps transients sharp but pitched material sounds unclean.
  • 2048 is a good starting point for a variety of material.
  • 4096 and 8192 grow progressively smoother and resolve more partials.
  • 16384 is very smooth but it softens attacks a lot.
  • 65536 creates textures rather than accurately representing the source audio. Any source audio turns into a slowly morphing pad.

The tradeoff is time vs frequency. Small FFT sizes keep detail in time but lose detail in frequency, whereas large sizes resolve plenty of detail in the spectrum but smear transients. Choose FFT size based on the source material.

Window

Hann, Hamming or Rectangular. Hann and Hamming taper the ends of each analysis frame, reducing leakage between neighbouring partials. Rectangular keeps the sharpest response but leaks more. Changing the window re-analyses the file.

Root

The frequency the stored ratios are measured against, from 20 Hz to 2000 Hz. It starts at the fundamental estimated from the file. If the file name contains a pitch that agrees with the analysis, such as Bass_A2_110.wav or Pad_C1.wav, that pitch anchors the register instead. Set it to the source's true fundamental to correct an octave error, or elsewhere to transpose the spectrum relative to the played note. Root does not re-analyse, so it still works when the file is missing.

The estimate is measured once over the whole file, so material that changes pitch can make it land between notes; across a glide it is expected to land mid-glide. It is not a pitch tracker, and it anchors only this default: it cancels out of playback and has no effect on timbre. Root is the control that moves the register. A session or preset keeps the stored root; reopening it does not re-read the file name.

Speed

How fast the frame sequence advances, independent of pitch: slowing the source stretches it in time without lowering the note.

Loop

Loop (default) wraps from the last frame back to the first. One-shot stops advancing at the last frame and holds that spectrum rather than cutting to silence.

Missing Source

The analysis is independent of the file once it has been made. If the file is moved, renamed or deleted, the stored frames still play, but FFT and Window are disabled because they need to read it again. Root, Speed, Loop and Additive Effects keep working. The status line keeps the duration, frame count and stored size but does not name the missing file; Load Audio... points at the file again.

Sessions and Presets

A saved DAW session stores the file path to the source audio, so reopening your project restores the sound and leaves FFT and Window options editable. A preset stores the frames and never the path or file name: loading one restores the sound, but FFT and Window stay disabled until the source file is loaded again. Root, Speed, Loop and Additive Effects remain available.

Geometric Oscillator

Overtones are spaced apart by the same interval, sounding quite sparse and bell-like.

  • Interval - Overtones are spaced apart by this many cents.
  • Brightness - Spectral tilt: 1 corresponds to white noise, 0.5 to pink, 0 to brown, and −1 to twice the slope of brown.

Arithmetic Oscillator

Overtones are spaced apart by the same frequency.

  • Step - Overtones are spaced apart by this many Hz.
  • Brightness - Spectral tilt: 1 corresponds to white noise, 0.5 to pink, 0 to brown, and −1 to twice the slope of brown.

Modulation Oscillator

Oscillator tones by modulation synthesis.

Algorithm

Frequency Modulation, Phase Modulation, Ring Modulation or Amplitude Modulation.

Carrier Tuning

Transpose the carrier by this many scale steps from the currently played note.

Modulator Tuning

Transpose the modulator by this many scale steps from the currently played note.

Mod Index

How strong the modulation is.

Carrier Feedback

How much the carrier bends its own phase.

Modulator Feedback

How much the modulator bends its own phase.

Split String

A plucked string split into two segments of different tension.

Brightness

Brightness: 0 keeps only the loop's low-passed signal, 1 is unfiltered.

Seg 1 Tuning

Length of the first string segment, in scale steps from the played note.

Seg 2 Tuning

Length of the second string segment, in scale steps from the played note.

Tension

The difference in tension between the two string segments. At 0, they act as one perfectly harmonic string. Higher values scatter more of the wave back and forth at the junction, and full tension approaches two strings that barely touch.

Amp Section

Envelope

Amp section holds the amplitude ADSR envelope and Output Gain.

Filter Section

A selection of filters are available. They each share the same Envelope, Resonance and Cutoff settings.

3-Pole Diode LPF

An acid style filter. If in doubt, turn resonance up to 100% for the absolute in squelch. (There was never any doubt).

4-Pole Ladder LPF

A classic sounding filter that saturates around the cutoff frequency.

4-Pole BPF

Fairly transparent band-pass.

2-Pole HPF

Fairly transparent high-pass.

Notch

A notch filter that cuts at the cutoff frequency. The higher the resonance setting, the narrower the notch.

Formant

Three band-pass resonators tuned to a vowel's formants, so the filter colours the sound like a voice. Cutoff sweeps the vowels /u/ → /o/ → /a/ → /e/ → /i/, low to high.

Keytracking

The keyboard icon beside the FILTER heading switches the filter cutoff keytracking on or off. With the icon crossed out, keytracking is disabled and cutoff spans frequencies 200-18000 Hz. Otherwise, keytracking is enabled and cutoff frequency sits some number of scale steps above the currently sounding note. Keytracked, cutoff spans 0-64 scale steps. At 0 st, the cutoff sits on the note's fundamental frequency. The filter envelope still sweeps on top of the cutoff, whether keytracked or not.

Character Section

Polyphony

  • Poly: Up to 24 voices with voice-stealing.
  • Mono: One voice, all envelopes restart when a new note is played.
  • Mono Legato: One voice, legato notes continue envelopes rather than restarting. Portamento allows for smooth pitch glides between pitches.

Warm Filter

A 2-pole Butterworth low-pass filter to transparently roll off treble.

Tuning Section

Tuning Source

Choose between Scala Files or MTS-ESP.

Source: Scala Files

Load up a scale and a mapping with the Load .scl and Load .kbm buttons. A small selection of these files were packaged in the zip.

Either file can also be dragged from the desktop onto the plugin window: one scale, one mapping, or both together. This automatically selects Scala Files as the tuning source.

Load Scale

Load a scale file (.scl), which sets up the synth for a particular scale.

Load Mapping

Load a keyboard mapping (.kbm), which sets how the scale is mapped to MIDI notes, and sets a reference MIDI note to a specific frequency.

Reset Tuning

Unload any present scl and kbm files to revert to standard tuning 12ed2.

Source: MTS-ESP Client

If you prefer to use an MTS-ESP master plugin to set your tuning, select MTS-ESP on Mutant Squelch to allow it to read the MTS-ESP tuning.

Lock Tuning

While locked, switching through presets won't affect your current set tuning.

Pitch Section

Transpose

Overall tuning offset from −3600 to +3600 cents.

Envelope

The ADSR envelopes allows you to shape the pitch of each voice over time.

Drift

Gradual, random instability on each voice's pitch.

Portamento

In mono legato mode, glide between notes.

Pitch Bend

The pitch wheel bends by scale steps rather than a fixed interval, so the ends of the wheel land exactly on pitches of the loaded tuning, even when an unequal tuning is loaded. This also works per-voice: Each sounding note bends from its own pitch to its own target, so every note of a chord lands on an exact pitch at the wheel extremes. Between the centre and an extreme the bend is smooth.

Bend Up

How many scale steps up the wheel bends when pushed fully up.

Bend Down

How many scale steps down the wheel bends when pulled fully down.

When the keyboard mapping leaves a key without a pitch, the bend holds the previous playable pitch instead of skipping ahead, so a sparse mapping can repeat a pitch over several steps.

MIDI

Mutant Squelch receives MIDI on all channels and merges them; there is no channel filter.

  • Note On: starts a voice. Velocity affects amplitude only. A velocity value of 1 is -40dB, 64 is -20dB, 100 is -8.57dB, and 127 is 0dB.
  • Note Off: releases the voice.
  • Sustain Pedal (CC 64): a key released while the pedal is down keeps sounding until the pedal lifts.
  • Pitch Bend: one global wheel, expressed in scale steps of the active tuning. Each sounding note resolves its own target, but every note follows the same wheel position. A bend on any channel moves that wheel.
  • All Sound Off (CC 120) and All Notes Off (CC 123): cut all voices, no release.

The following are not supported:

  • Mod wheel (CC 1), aftertouch, other continuous controllers and MIDI learn.
  • Program change. Use the host's preset system or the preset selector instead.
  • MPE and per-channel pitch bend. Pitch bend is one global wheel.
  • MIDI clock and transport sync.
  • MIDI output.

The pitch-bend range is set in the Pitch section and is owned by the plugin; it does not follow RPN or the host's pitch-bend sensitivity. Notes are mapped through the active tuning, so a key that the keyboard mapping leaves unmapped is ignored rather than falling back to 12ed2.

Up to 24 voices sound at once; the oldest voice is stolen when a 25th note arrives.

GUI

The palette button in the bottom-left corner cycles the accent colour. Use whatever you like best; your choice is saved in the plugin's user settings file and restored the next time the GUI opens.

Long-throw Cutoff fader: this is the one parameter you probably want to play musically, and a longer fader gives you better control.

Spectrum analyser: horizontal scale is logarithmic, spectral tilt is 4.5 dB/oct.

Settings and Library

Mutant Squelch keeps a few user preferences in a small file called settings.xml.

It's plain XML, so you can open it in any text editor. Delete the file if you want to reset everything to defaults.

  • Linux: ~/.config/Sevish/MutantSquelch/settings.xml
  • macOS: ~/Library/Application Support/Sevish/MutantSquelch/settings.xml
  • Windows: %APPDATA%\Sevish\MutantSquelch\settings.xml

Inside you'll find:

  • accentIndex - the accent colour you picked with the palette button. 0 is the default teal.
  • editorWidth and editorHeight - the size you last left the window at. If the size doesn't match the interface's aspect ratio, it's ignored and the window opens at the default size.
  • sclDir - the folder the Load .scl picker opens in. It updates whenever you load a scale.
  • kbmDir - same as above, for Load .kbm and mappings.
  • audioDir - the folder the Resynthesis Load Audio... picker opens in. The plugin only reads this one, so it stays empty unless you fill it in. Point it at your samples folder and the audio picker will start there.

In the same folder as the settings file, you'll see a Presets subfolder. All of your saved presets will be stored here.

Presets

The preset manager lets you save and load the patches you create with Mutant Squelch. The preset drop-down box at the bottom of the plugin interface lets you access all of the built-in Factory presets as well as any User presets you have saved.

The Save icon always works as a Save As function, so if you use one preset as a starting preset for another, you won't accidentally overwrite that starting preset. If you do want to overwrite the currently loaded preset, the filename is automatically filled out for convenience.
